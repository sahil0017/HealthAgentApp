TabHoldsEntry pointsData / hardware
TodayDaily briefing, rings, alerts for you, area alert cardCards deep-link to Health, Agent, NearbyCommand centre, devices, location (area)
VaultReports, scan, review, searchScan button, Report ready pushCamera, files, documents API
HealthLabs, vitals, devices, goals, trends, lifestyleBiomarker detail, Care planHealthKit / Health Connect, biomarkers API
AgentChat, plan, approvals, doctor visit prep, activityFloating "Ask" on every screenQuestions API, MCP, research

Rule: five tabs only. Everything else is a screen reached from a card or More, never a sixth tab. One profile switcher (top right) applies to every tab. The agent is available from any screen through a floating Ask button and can open any screen for the user.
