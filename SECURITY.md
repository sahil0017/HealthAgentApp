# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull request. Use GitHub's private vulnerability reporting for this repository:

<https://github.com/sahil0017/HealthAgentApp/security/advisories/new>

If GitHub indicates that private vulnerability reporting is unavailable, contact the repository owner privately and ask them to enable it. Do not include real health information, personal data, credentials, or private documents in a report.

## Scope and expectations

CORTEX is a local-development prototype and is not suitable for production use. Reports about exploitable behavior in this repository are welcome. Please include a concise description, affected component, and safe reproduction steps using synthetic data only. Please allow time for investigation and a fix before sharing details publicly.

There is no guaranteed response time or security support commitment.
